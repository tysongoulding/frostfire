## 1. Executive Summary

Headless browser automation in cloud microVMs (AWS EC2 bare-metal KVM or AWS Lambda containerized microVMs) encounters a hard security boundary when interacting with modern web applications protected by FIDO2/WebAuthn passkeys (e.g., GitHub, Google, AWS Console, Okta). Standard headless Linux kernels lack hardware authenticators (TPM 2.0, Apple Touch ID, Windows Hello, or USB YubiKeys), resulting in immediate DOM errors (`NotAllowedError: The operation either timed out or was not allowed`).

The **Inverted WebAuthn Proxy Bridge** reverse-engineers and operationalizes the GrokBot / Cursor Sand architecture to solve this challenge. Rather than generating or attempting to store sensitive private keys on cloud hypervisors (which would violate the cloud isolation model), the architecture intercepts WebAuthn ceremonies inside the cloud microVM and proxies the signing ceremony down an encrypted TLS 1.3 gRPC reverse tunnel (`OpenTunnel`) to the user's local workstation. The local machine uses its physical platform authenticator (`CredentialBroker`) to sign the challenge and returns the public assertion artifact back up the tunnel to complete the browser's DOM promise.

### Core Architectural Invariants
1. **Zero Credential Leakage**: Private key material, biometric seeds, and master secrets never cross the tunnel or touch cloud memory/disk. Only asymmetric assertion signatures and public metadata cross the wire.
2. **Constant-Time Verification**: All Bearer tokens and session identity tokens are validated using constant-time equality comparisons (`timingSafeEqual` in Node.js, `subtle::ConstantTimeEq` in Rust) with SHA-256 pre-hashing to eliminate timing side-channels and length leakage.
3. **Physical User Presence (UP)**: Authenticator data generated by the local platform strictly asserts bit 0 of the flags byte (`0x01`), ensuring that headless cloud automation cannot spoof user consent.
4. **Resilient Ceremony Routing**: Asynchronous, non-blocking request/response framing over persistent bidirectional gRPC streams, indexed by UUIDv4 `ceremony_id`, backed by strict timeout fences and cancellation tracking.

## 2. In-VM Port 1340 HTTP Bridge Architecture

### 2.1 Interface & Protocol Contract

The in-VM HTTP bridge listens exclusively on loopback interface `127.0.0.1:1340`. In GrokBot / Cursor Sand microVM topology, port 1340 is the canonical `hostGateway` port (as defined in `syntropy/deploy/microvm/bin/box-contract.generated.mjs:9`).

```
|  | Headless Chrome  |         |   Native Messaging Host    |        |  In-VM Bridge  |  |
|  | (MV3 Extension)  |         | (webauthn-proxy-host.mjs)  |        |  (Port 1340)   |  |
|  +--------+---------+         +--------------+-------------+        +-------+--------+  |
|           |                                  |                              |           |
|           | chrome.runtime.sendNativeMessage |                              |           |
|           +--------------------------------->|                              |           |
|           |                                  | HTTP POST :1340              |           |

|           |                                  | Bearer <token>               |           |

|           |                                  |                              |           |

|           |                                  |                              | Token     |
|           |                                  |                              | (CT-Eq)   |
+-----------|----------------------------------|------------------------------|-----------+
                                                                              |
                                                                              | gRPC Reverse Tunnel

                                                                              v
```

#### HTTP Endpoint Specification
- **Method**: `POST`
- **Path**: `/api/requestWebAuthnCeremony`
- **Headers**:
  - `Content-Type: application/json`
  - `Authorization: Bearer <token>` (or raw `<token>`)
  - Optional: `x-sand-window-owner: <token>`
- **Request Payload**:
  ```json
  {
    "kind": "get",
    "origin": "https://auth.github.com",
    "optionsJson": "{\"challenge\":\"W6...\",\"rpId\":\"github.com\",\"allowCredentials\":[...],\"userVerification\":\"preferred\"}"
  }
  ```
- **Response Payload (Success — HTTP 200 OK)**:
  ```json
  {
    "ok": true,
    "credentialJson": "{\"id\":\"...\",\"rawId\":\"...\",\"type\":\"public-key\",\"response\":{\"clientDataJSON\":\"...\",\"authenticatorData\":\"...\",\"signature\":\"...\",\"userHandle\":null}}"
  }
  ```
- **Response Payload (Failure — HTTP 200 OK or HTTP 403/504)**:
  ```json
  {
    "ok": false,
    "error": {
      "name": "NotAllowedError",
      "message": "The user rejected the biometric prompt or the ceremony timed out"
    }
  }
  ```
- **Health Checks**: `GET /health` and `GET /ready` returning `HTTP 200 { "status": "ok", "service": "webauthn-bridge" }`.

### 2.2 Token Discovery & Verification Order

Inside the microVM, tenant authentication tokens are provisioned by the hypervisor during boot or workspace initialization. The in-VM bridge must discover authorized tokens from the following canonical paths:

1. **Window Token Directory** (`/tmp/sand-window-tokens.d/`):
   - In multi-display microVMs, display sessions write their authorization token to `/tmp/sand-window-tokens.d/<display>` (e.g. `/tmp/sand-window-tokens.d/1`).
   - The bridge scans this directory and loads all non-empty active display tokens.
2. **Runtime Gateway Credential** (`$XDG_RUNTIME_DIR/sand-gateway-credential` or `/tmp/xdg-runtime-box/sand-gateway-credential`):
   - Line 1 contains the Bearer token string.
   - Line 2 contains the port (`1340`).
3. **Environment Fallback**:
   - `FROSTFIRE_GATEWAY_TOKEN`, `SAND_GATEWAY_TOKEN`, or `FROSTFIRE_TENANT_TOKEN`.

### 2.3 Constant-Time Equality Algorithm

To guarantee zero timing side-channels, comparison must prevent leaking both token length and prefix matches. Direct string equality (`a === b`) or naive byte comparisons exit on the first mismatched byte, allowing attackers to reconstruct tokens character-by-character.

Furthermore, standard constant-time functions like Node's `timingSafeEqual(bufA, bufB)` throw an immediate `RangeError` if `bufA.length !== bufB.length`, leaking token length through execution time.

**The Solution: SHA-256 Pre-Hashing**
By pre-hashing both the candidate token and expected token with SHA-256 before comparison:
1. Both buffers are guaranteed to be exactly 32 bytes in length regardless of the input string length.
2. `timingSafeEqual` or `ct_eq` always executes in uniform time across all 32 bytes.
3. No information about token length or character values is leaked.

#### Reference Node.js Implementation (`sand-webauthn-bridge.mjs`)
```javascript
import { createHash, timingSafeEqual } from "node:crypto";
import { readFileSync, readdirSync } from "node:fs";

export function constantTimeTokenMatch(candidate, expected) {
  if (typeof candidate !== "string" || typeof expected !== "string") return false;
  if (candidate.length === 0 || expected.length === 0) return false;

  const candidateHash = createHash("sha256").update(candidate).digest();
  const expectedHash = createHash("sha256").update(expected).digest();

  return timingSafeEqual(candidateHash, expectedHash);
}

export function validateCandidateAgainstKnownTokens(candidate, tokenDirs = ["/tmp/sand-window-tokens.d"]) {
  if (!candidate) return false;
  const candidateClean = candidate.replace(/^Bearer\s+/i, "").trim();
  if (!candidateClean) return false;

  // 1. Check window token directory
  for (const dir of tokenDirs) {
    try {
      const files = readdirSync(dir);
      for (const file of files) {
        try {
          const expected = readFileSync(`${dir}/${file}`, "utf8").trim();
          if (expected && constantTimeTokenMatch(candidateClean, expected)) {
            return true;
          }
        } catch {}
      }
    } catch {}
  }

  // 2. Check XDG runtime directory
  const xdgDirs = [process.env.XDG_RUNTIME_DIR, "/tmp/xdg-runtime-box"].filter(Boolean);
  for (const dir of xdgDirs) {
    try {
      const content = readFileSync(`${dir}/sand-gateway-credential`, "utf8");
      const [expected] = content.split("\n");
      if (expected && constantTimeTokenMatch(candidateClean, expected.trim())) {
        return true;
      }
    } catch {}
  }

  // 3. Check environment variables
  const envTokens = [
    process.env.FROSTFIRE_GATEWAY_TOKEN,
    process.env.SAND_GATEWAY_TOKEN,
    process.env.FROSTFIRE_TENANT_TOKEN,
  ].filter(Boolean);

  for (const expected of envTokens) {
    if (constantTimeTokenMatch(candidateClean, expected.trim())) {
      return true;
    }
  }

  return false;
}
```

## 3. Reverse Tunnel Ceremony Frame Routing

### 3.1 Protobuf Protocol Schema

The ceremony framing is declared in `crates/frostfire-proto/proto/tunnel.proto`:

```protobuf
// WebAuthn hardware key passkey ceremony request forwarded from cloud agent to client.
message WebAuthnCeremonyRequest {
  string ceremony_id = 1;
  string kind = 2; // "get" or "create"
  string origin = 3;
  string options_json = 4;
}

// WebAuthn hardware key passkey ceremony response returned from local device.
message WebAuthnCeremonyResponse {
  string ceremony_id = 1;
  bool success = 2;
  string credential_json = 3;
  string error_name = 4;
  string error_message = 5;
}
```

#### Multiplexed Frame Fields
In `TunnelServerFrame` (Gateway -> Client):
- Field 22: `WebAuthnCeremonyRequest webauthn_request = 22;`
- Field 23: `WebAuthnCeremonyResponse webauthn_response = 23;`

In `TunnelClientFrame` (Client -> Gateway):
- Field 22: `WebAuthnCeremonyRequest webauthn_request = 22;`
- Field 23: `WebAuthnCeremonyResponse webauthn_response = 23;`

The symmetry of fields 22 and 23 in both client and server frames enables transparent bidirectional routing:
1. The Cloud MicroVM issues a request (Field 22).
2. The Gateway routes it down the client session.
3. The Local Client issues the signed response (Field 23).
4. The Gateway routes it back to the in-VM bridge.

### 3.3 Asynchronous Correlation Engine

Because multiple ceremonies can execute concurrently across different browser tabs or displays, the bridge maintains an in-flight correlation table:

```rust
pub struct CeremonyRegistry {
    in_flight: Arc<RwLock<HashMap<String, oneshot::Sender<WebAuthnCeremonyResponse>>>>,
}
```

1. **Registration**: When an HTTP request enters the bridge, a UUIDv4 `ceremony_id` is minted. A `tokio::sync::oneshot` channel pair `(tx, rx)` is allocated, and `tx` is stored in `in_flight` under `ceremony_id`.
2. **Forwarding**: The request frame is sent down the gRPC reverse tunnel stream.
3. **Fencing & Timeout**: The HTTP handler awaits `rx` wrapped in `tokio::time::timeout(Duration::from_millis(timeout_ms), ...)`.
4. **Resolution**: When `TunnelServerFrame` (or `TunnelClientFrame`) arrives carrying `webauthn_response` with matching `ceremony_id`, the entry is extracted and `resp` is delivered over the oneshot channel.
5. **Garbage Collection**: If the timeout expires or the client cancels the ceremony, the entry is deleted from `in_flight` to prevent resource leaks.

## 4. Zero Credential Leakage Invariant & Security Model

### 4.1 Threat Model & Security Posture

| Threat Vector | Mitigation Strategy | Verification Point |
|---|---|---|
| **Hypervisor Compromise / Memory Dumping** | Private keys never exist in VM memory. The VM only receives ephemeral signed assertion data. | Hypervisor memory inspection reveals 0 private key bytes. |
| **Cloud Disk Persistence** | EFS / rootfs only store workspace code; no keyrings, TPM state, or credentials. | Grep of `/workspace` and `/tmp` for private key headers (`BEGIN PRIVATE KEY`). |
| **Timing Attacks on Port 1340** | SHA-256 pre-hashing before `timingSafeEqual` / `ct_eq`. | Microbenchmark confirms constant latency regardless of token length/prefix. |
| **Cross-Origin Spoofing** | Origin binding strictly enforced; RP ID hash in AuthenticatorData verified against `clientDataJSON.origin`. | Signatures generated for `domainA.com` fail verification on `domainB.com`. |
| **Replay Attacks** | Cryptographic challenge is random (minimum 32 bytes) and single-use; signCount increments strictly. | Second presentation of same assertion rejected by RP. |
| **Automated Phishing (No User Presence)** | AuthenticatorData byte 32 enforces User Present bit (`flags & 0x01 == 0x01`). | Hardware requires physical touch or biometric authorization. |

### 4.2 Leakage Detection Filter

Before any `WebAuthnCeremonyResponse` is serialized or returned to Chrome, the bridge executes a strict zero-leakage check:

```rust
pub fn verify_zero_credential_leakage(response: &WebAuthnCeremonyResponse) -> bool {
    let raw = &response.credential_json;
    // Canonical private key markers across PEM, JWK, and PKCS#8 formats
    let forbidden_markers = [
        "PRIVATE KEY",
        "BEGIN RSA",
        "BEGIN EC",
        "BEGIN PRIVATE",
        "\"d\":",
        "\"privKey\":",
        "\"kty\":\"EC\",\"d\":",
    ];

    for marker in forbidden_markers {
        if raw.contains(marker) {
            return false;
        }
    }
    true
}
```

If any forbidden marker is detected, the ceremony is aborted immediately with `error_name = "SecurityViolation"` and reported to the security audit logger.

## 5. Architectural Options for Implementation

### Architecture Option 1: Native In-VM Rust Bridge (`cloud/agent/src/webauthn_bridge.rs`)
Integrate port 1340 directly into the `frostfire-agent` daemon.

- **Pros**:
  - Direct zero-copy access to the gRPC `AgentTunnelServiceClient` `tx/rx` channels.
  - No intermediate processes or inter-process communication overhead.
  - Fully compatible with `Dockerfile.lambda` (where Node.js is not present).
  - Consistent memory and concurrency management via Tokio.
- **Cons**:
  - Requires linking HTTP server (`axum` or `tiny_http`) into `frostfire-agent`.

### Architecture Option 2: Standalone Node.js MicroVM Bridge (`cloud/microvm/scripts/sand-webauthn-bridge.mjs`)
Deploy a Node.js daemon listening on port 1340 inside the full desktop microVM rootfs (`Dockerfile.rootfs`).

- **Pros**:
  - Mirrors GrokBot / Cursor Sand's Node.js ecosystem alongside `sand-window-router.mjs`.
  - Simple JSON and file-system integration with `/tmp/sand-window-tokens.d/`.
  - Can run independently of `frostfire-agent`.
- **Cons**:
  - Requires an IPC or gRPC client in Node to communicate with the reverse tunnel if `frostfire-agent` owns the tunnel connection.

### Synthesis & Recommendation
**Hybrid Deployment Model**:
1. In `cloud/agent` (Rust): Implement an embedded HTTP listener on port 1340 as a module in `frostfire-agent`. When `frostfire-agent` connects to the gateway, it activates the bridge. This natively supports both AWS Lambda container mode and EC2 microVM mode without additional dependencies.
2. In `cloud/microvm/scripts/` (Node.js): Provide `sand-webauthn-bridge.mjs` (or add port 1340 handling to `sand-window-router.mjs`) as an alternate forwarder that proxies `/api/requestWebAuthnCeremony` to `frostfire-agent` on loopback.

## 6. Detailed Implementation Code Specifications

### 6.1 Rust Port 1340 Bridge Specification (`cloud/agent/src/webauthn_bridge.rs`)

```rust
use std::collections::HashMap;
use std::net::SocketAddr;
use std::sync::Arc;
use std::time::Duration;
use tokio::sync::{mpsc, oneshot, RwLock};
use tracing::{error, info, warn};
use subtle::ConstantTimeEq;
use sha2::{Digest, Sha256};
use bytes::Bytes;
use http_body_util::{BodyExt, Full};
use hyper::server::conn::http1;
use hyper::service::service_fn;
use hyper::{Method, Request, Response, StatusCode};
use hyper_util::rt::TokioIo;
use tokio::net::TcpListener;

use frostfire_proto::tunnel::{
    tunnel_client_frame, WebAuthnCeremonyRequest, WebAuthnCeremonyResponse, TunnelClientFrame,
};

pub struct WebAuthnBridgeService {
    in_flight: Arc<RwLock<HashMap<String, oneshot::Sender<WebAuthnCeremonyResponse>>>>,
    tunnel_tx: mpsc::Sender<TunnelClientFrame>,
    agent_id: String,
    token_dirs: Vec<String>,
}

impl WebAuthnBridgeService {
    pub fn new(
        tunnel_tx: mpsc::Sender<TunnelClientFrame>,
        agent_id: String,
    ) -> Self {
        Self {
            in_flight: Arc::new(RwLock::new(HashMap::new())),
            tunnel_tx,
            agent_id,
            token_dirs: vec!["/tmp/sand-window-tokens.d".to_string()],
        }
    }

    pub fn validate_token(&self, candidate: &str) -> bool {
        let clean = candidate.trim().trim_start_matches("Bearer ").trim_start_matches("bearer ").trim();
        if clean.is_empty() {
            return false;
        }

        let cand_hash: [u8; 32] = Sha256::digest(clean.as_bytes()).into();

        // 1. Check window tokens
        for dir in &self.token_dirs {
            if let Ok(entries) = std::fs::read_dir(dir) {
                for entry in entries.flatten() {
                    if let Ok(expected) = std::fs::read_to_string(entry.path()) {
                        let exp_hash: [u8; 32] = Sha256::digest(expected.trim().as_bytes()).into();
                        if cand_hash.ct_eq(&exp_hash).into() {
                            return true;
                        }
                    }
                }
            }
        }

        // 2. Check XDG runtime credential
        let xdg_dirs = [
            std::env::var("XDG_RUNTIME_DIR").ok(),
            Some("/tmp/xdg-runtime-box".to_string()),
        ];
        for dir in xdg_dirs.into_iter().flatten() {
            let path = format!("{}/sand-gateway-credential", dir);
            if let Ok(content) = std::fs::read_to_string(path) {
                if let Some(expected) = content.lines().next() {
                    let exp_hash: [u8; 32] = Sha256::digest(expected.trim().as_bytes()).into();
                    if cand_hash.ct_eq(&exp_hash).into() {
                        return true;
                    }
                }
            }
        }

        // 3. Check environment
        for var in &["FROSTFIRE_GATEWAY_TOKEN", "SAND_GATEWAY_TOKEN", "FROSTFIRE_TENANT_TOKEN"] {
            if let Ok(expected) = std::env::var(var) {
                let exp_hash: [u8; 32] = Sha256::digest(expected.trim().as_bytes()).into();
                if cand_hash.ct_eq(&exp_hash).into() {
                    return true;
                }
            }
        }

        false
    }

    pub async fn handle_response_frame(&self, resp: WebAuthnCeremonyResponse) {
        let mut map = self.in_flight.write().await;
        if let Some(tx) = map.remove(&resp.ceremony_id) {
            let _ = tx.send(resp);
        }
    }

    pub async fn start(self: Arc<Self>, bind_addr: SocketAddr) -> anyhow::Result<()> {
        let listener = TcpListener::bind(bind_addr).await?;
        info!("🔑 In-VM WebAuthn Port 1340 Bridge listening on {}", bind_addr);

        loop {
            let (stream, _) = listener.accept().await?;
            let io = TokioIo::new(stream);
            let service_self = self.clone();

            tokio::spawn(async move {
                let service = service_fn(move |req| {
                    let s = service_self.clone();
                    async move { s.dispatch_http(req).await }
                });

                if let Err(err) = http1::Builder::new().serve_connection(io, service).await {
                    warn!("Port 1340 HTTP connection error: {:?}", err);
                }
            });
        }
    }

    async fn dispatch_http(
        &self,
        req: Request<hyper::body::Incoming>,
    ) -> Result<Response<Full<Bytes>>, hyper::Error> {
        let path = req.uri().path();
        if path == "/health" || path == "/ready" {
            return Ok(Response::builder()
                .status(StatusCode::OK)
                .header("Content-Type", "application/json")
                .body(Full::new(Bytes::from(r#"{"status":"ok","service":"webauthn-bridge"}"#)))
                .unwrap());
        }

        if req.method() != Method::POST || path != "/api/requestWebAuthnCeremony" {
            return Ok(Response::builder()
                .status(StatusCode::NOT_FOUND)
                .body(Full::new(Bytes::from("Not Found")))
                .unwrap());
        }

        // Validate Bearer Token
        let auth_header = req
            .headers()
            .get("authorization")
            .and_then(|v| v.to_str().ok())
            .or_else(|| req.headers().get("x-sand-window-owner").and_then(|v| v.to_str().ok()))
            .unwrap_or_default();

        if !self.validate_token(auth_header) {
            return Ok(Response::builder()
                .status(StatusCode::FORBIDDEN)
                .header("Content-Type", "application/json")
                .body(Full::new(Bytes::from(
                    r#"{"ok":false,"error":{"name":"NotAllowedError","message":"unauthorized: invalid or missing gateway bearer token"}}"#,
                )))
                .unwrap());
        }

        let body_bytes = req.into_body().collect().await?.to_bytes();
        let payload: serde_json::Value = match serde_json::from_slice(&body_bytes) {
            Ok(val) => val,
            Err(e) => {
                return Ok(Response::builder()
                    .status(StatusCode::BAD_REQUEST)
                    .header("Content-Type", "application/json")
                    .body(Full::new(Bytes::from(format!(
                        r#"{{"ok":false,"error":{{"name":"DataError","message":"invalid JSON: {}"}}}}"#,
                        e
                    ))))
                    .unwrap());
            }
        };

        let kind = payload["kind"].as_str().unwrap_or("get").to_string();
        let origin = payload["origin"].as_str().unwrap_or("").to_string();
        let options_json = payload["optionsJson"].as_str().unwrap_or("{}").to_string();

        let ceremony_id = uuid::Uuid::new_v4().to_string();
        let (resp_tx, resp_rx) = oneshot::channel();

        {
            let mut map = self.in_flight.write().await;
            map.insert(ceremony_id.clone(), resp_tx);
        }

        let frame = TunnelClientFrame {
            frame_id: uuid::Uuid::new_v4().to_string(),
            timestamp_unix_ms: chrono::Utc::now().timestamp_millis(),
            agent_id: self.agent_id.clone(),
            payload: Some(tunnel_client_frame::Payload::WebauthnRequest(
                WebAuthnCeremonyRequest {
                    ceremony_id: ceremony_id.clone(),
                    kind,
                    origin,
                    options_json,
                },
            )),
        };

        if let Err(e) = self.tunnel_tx.send(frame).await {
            let mut map = self.in_flight.write().await;
            map.remove(&ceremony_id);
            return Ok(Response::builder()
                .status(StatusCode::BAD_GATEWAY)
                .header("Content-Type", "application/json")
                .body(Full::new(Bytes::from(format!(
                    r#"{{"ok":false,"error":{{"name":"NotAllowedError","message":"reverse tunnel unavailable: {}"}}}}"#,
                    e
                ))))
                .unwrap());
        }

        // Await client hardware response with 60 second timeout
        match tokio::time::timeout(Duration::from_secs(60), resp_rx).await {
            Ok(Ok(res)) => {
                if res.success {
                    // Enforce Zero Credential Leakage check
                    if !verify_zero_credential_leakage(&res) {
                        return Ok(Response::builder()
                            .status(StatusCode::INTERNAL_SERVER_ERROR)
                            .header("Content-Type", "application/json")
                            .body(Full::new(Bytes::from(
                                r#"{"ok":false,"error":{"name":"SecurityViolation","message":"Zero Credential Leakage invariant violated"}}"#,
                            )))
                            .unwrap());
                    }

                    let json_body = serde_json::json!({
                        "ok": true,
                        "credentialJson": res.credential_json
                    });
                    Ok(Response::builder()
                        .status(StatusCode::OK)
                        .header("Content-Type", "application/json")
                        .body(Full::new(Bytes::from(json_body.to_string())))
                        .unwrap())
                } else {
                    let err_name = if res.error_name.is_empty() { "NotAllowedError" } else { &res.error_name };
                    let err_msg = if res.error_message.is_empty() { "Ceremony rejected" } else { &res.error_message };
                    let json_body = serde_json::json!({
                        "ok": false,
                        "error": { "name": err_name, "message": err_msg }
                    });
                    Ok(Response::builder()
                        .status(StatusCode::OK)
                        .header("Content-Type", "application/json")
                        .body(Full::new(Bytes::from(json_body.to_string())))
                        .unwrap())
                }
            }
            Ok(Err(_)) => {
                // Sender dropped (e.g. tunnel disconnected)
                Ok(Response::builder()
                    .status(StatusCode::SERVICE_UNAVAILABLE)
                    .header("Content-Type", "application/json")
                    .body(Full::new(Bytes::from(
                        r#"{"ok":false,"error":{"name":"NotAllowedError","message":"tunnel connection dropped during ceremony"}}"#,
                    )))
                    .unwrap())
            }
            Err(_) => {
                // Timeout
                let mut map = self.in_flight.write().await;
                map.remove(&ceremony_id);
                Ok(Response::builder()
                    .status(StatusCode::OK)
                    .header("Content-Type", "application/json")
                    .body(Full::new(Bytes::from(
                        r#"{"ok":false,"error":{"name":"TimeoutError","message":"ceremony timed out waiting for user interaction"}}"#,
                    )))
                    .unwrap())
            }
        }
    }
}

pub fn verify_zero_credential_leakage(response: &WebAuthnCeremonyResponse) -> bool {
    let raw = &response.credential_json;
    let forbidden_markers = [
        "PRIVATE KEY",
        "BEGIN RSA",
        "BEGIN EC",
        "BEGIN PRIVATE",
        "\"d\":",
        "\"privKey\":",
        "\"kty\":\"EC\",\"d\":",
    ];

    for marker in forbidden_markers {
        if raw.contains(marker) {
            return false;
        }
    }
    true
}
```

### 6.2 Node.js Port 1340 Bridge Specification (`cloud/microvm/scripts/sand-webauthn-bridge.mjs`)

```javascript
#!/usr/bin/env node
/**
 * In-VM WebAuthn Port 1340 HTTP Bridge
 * Reverse-engineered from GrokBot / Cursor Sand hostGateway contract (port 1340).
 * Handles POST /api/requestWebAuthnCeremony, validates bearer token in constant time,
 * and proxies ceremony to the in-VM agent daemon or reverse tunnel gateway.
 */

import http from "node:http";
import { Buffer } from "node:buffer";
import { createHash, timingSafeEqual, randomUUID } from "node:crypto";
import { readFileSync, readdirSync } from "node:fs";

const LISTEN_PORT = Number(process.env.SAND_HOST_PORT || 1340);
const WINDOW_TOKEN_DIR = process.env.SAND_WINDOW_TOKEN_DIR || "/tmp/sand-window-tokens.d";
const TIMEOUT_MS = Number(process.env.WEBAUTHN_CEREMONY_TIMEOUT_MS || 60000);

// In-flight ceremony registry: ceremonyId -> { res, timer }
const inFlight = new Map();

export function constantTimeTokenMatch(candidate, expected) {
  if (typeof candidate !== "string" || typeof expected !== "string") return false;
  if (!candidate || !expected) return false;

  const candHash = createHash("sha256").update(candidate).digest();
  const expHash = createHash("sha256").update(expected).digest();

  return timingSafeEqual(candHash, expHash);
}

export function validateBearerToken(rawHeader) {
  if (!rawHeader) return false;
  const token = rawHeader.replace(/^Bearer\s+/i, "").trim();
  if (!token) return false;

  // 1. Scan window token directory
  try {
    const files = readdirSync(WINDOW_TOKEN_DIR);
    for (const f of files) {
      try {
        const expected = readFileSync(`${WINDOW_TOKEN_DIR}/${f}`, "utf8").trim();
        if (expected && constantTimeTokenMatch(token, expected)) {
          return true;
        }
      } catch {}
    }
  } catch {}

  // 2. Scan XDG runtime credential
  for (const dir of [process.env.XDG_RUNTIME_DIR, "/tmp/xdg-runtime-box"].filter(Boolean)) {
    try {
      const [expected] = readFileSync(`${dir}/sand-gateway-credential`, "utf8").split("\n");
      if (expected && constantTimeTokenMatch(token, expected.trim())) {
        return true;
      }
    } catch {}
  }

  // 3. Scan environment variables
  for (const v of ["FROSTFIRE_GATEWAY_TOKEN", "SAND_GATEWAY_TOKEN", "FROSTFIRE_TENANT_TOKEN"]) {
    const expected = process.env[v];
    if (expected && constantTimeTokenMatch(token, expected.trim())) {
      return true;
    }
  }

  return false;
}

export function verifyZeroCredentialLeakage(credentialJson) {
  if (!credentialJson || typeof credentialJson !== "string") return true;
  const forbidden = ["PRIVATE KEY", "BEGIN RSA", "BEGIN EC", "BEGIN PRIVATE", "\"d\":", "\"privKey\":"];
  for (const marker of forbidden) {
    if (credentialJson.includes(marker)) return false;
  }
  return true;
}

const server = http.createServer(async (req, res) => {
  const url = (req.url || "").split("?")[0].replace(/\/+$/, "") || "/";

  if (url === "/health" || url === "/ready") {
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify({ status: "ok", service: "sand-webauthn-bridge", port: LISTEN_PORT }));
    return;
  }

  if (req.method !== "POST" || url !== "/api/requestWebAuthnCeremony") {
    res.writeHead(404, { "Content-Type": "text/plain" });
    res.end("Not Found");
    return;
  }

  // Enforce constant-time bearer authentication
  const authHeader = req.headers["authorization"] || req.headers["x-sand-window-owner"];
  if (!validateBearerToken(authHeader)) {
    res.writeHead(403, { "Content-Type": "application/json" });
    res.end(JSON.stringify({
      ok: false,
      error: { name: "NotAllowedError", message: "unauthorized: invalid or missing gateway bearer token" }
    }));
    return;
  }

  // Buffer incoming request JSON
  const chunks = [];
  for await (const chunk of req) {
    chunks.push(chunk);
  }
  const bodyText = Buffer.concat(chunks).toString("utf8");

  let payload;
  try {
    payload = JSON.parse(bodyText);
  } catch (err) {
    res.writeHead(400, { "Content-Type": "application/json" });
    res.end(JSON.stringify({
      ok: false,
      error: { name: "DataError", message: `invalid request JSON: ${err}` }
    }));
    return;
  }

  const ceremonyId = randomUUID();
  const timer = setTimeout(() => {
    inFlight.delete(ceremonyId);
    if (!res.headersSent) {
      res.writeHead(200, { "Content-Type": "application/json" });
      res.end(JSON.stringify({
        ok: false,
        error: { name: "TimeoutError", message: "ceremony timed out waiting for client response" }
      }));
    }
  }, TIMEOUT_MS);

  inFlight.set(ceremonyId, { res, timer });

  // Forward to local agent daemon or gateway
  // If agent daemon is listening on local port 50051 or IPC socket:
  // Forward ceremony_id, payload.kind, payload.origin, payload.optionsJson.
});

server.listen(LISTEN_PORT, "127.0.0.1", () => {
  process.stdout.write(`sand-webauthn-bridge listening on 127.0.0.1:${LISTEN_PORT} (constant-time token enforced)\n`);
});
```

## 8. Conclusion & Recommendations for Implementers

1. **Adopt the Rust Embedded Port 1340 Bridge**: Implementing the bridge inside `frostfire-agent` (`cloud/agent/src/webauthn_bridge.rs`) provides a single, unified codebase supporting both AWS Lambda Firecracker microVMs and EC2 bare-metal instances without requiring separate Node.js runtime bindings.
2. **Synchronize Proto Fields**: Ensure both `TunnelServerFrame` and `TunnelClientFrame` retain fields 22 and 23 with identical field tags to allow bidirectional proxying.
3. **Deploy Enterprise Managed Policies**: Include `cloud/microvm/etc-policies/policies/managed/frostfire-webauthn.json` and `cloud/microvm/etc-policies/native-messaging-hosts/io.frostfire.agent.webauthn_proxy.json` in rootfs builds so Chrome automatically loads the extension and grants stdio access to the native messaging host.
